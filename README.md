# 수행평가 점수 확인과 서명

학생이 아이패드에서 자기 수행평가 점수와 그 점수가 나온 이유를 읽고 화면에 서명하는 도구입니다. 납득하지 못하면 서명하지 않고 질문을 남깁니다.

주소: https://zzobakg-boop.github.io/suhaeng-reason/

## 학생 정보는 이 주소로 올라가지 않습니다
- 이 저장소와 주소에는 프로그램 파일만 있습니다. 나이스 일람표 PDF, 이유 자료(json), 서명, 확인 기록은 아이패드 안(IndexedDB)에만 저장됩니다.
- 프로그램은 바깥 주소를 부르지 않습니다. 한 번 열어 홈 화면에 추가하면 인터넷 없이도 열립니다.

## 쓰는 순서
1. 나이스 [성적] → [수행평가조회/통계] → [수행평가조회] → [학급일람표조회-전체영역] → PDF 저장.
2. 일람표 PDF와 그 반 이유 자료를 에어드롭으로 아이패드에 옮깁니다. 메일·메신저로 보내지 않습니다.
3. 사파리로 이 주소를 열고 공유 → 홈 화면에 추가. 이후 아이콘으로만 엽니다(사파리가 7일 동안 열지 않은 사이트의 저장 자료를 지울 수 있어서입니다).
4. 일람표 올리기 → 이유 자료 올리기 → 일람표 칸과 이유 자료 점수 맞추기 → 점수가 다른 학생이 0명인지 확인.
5. 교사 비밀번호(숫자 4자리 이상)를 넣고 학생 서명 시작. 학생은 자기 이름을 누르고 번호를 넣습니다. 이 단계는 잘못 누른 것을 막을 뿐이니, 서명은 교사가 지켜보는 자리에서 받습니다.
6. 끝나면 서명 PDF와 확인 기록을 받아 학교 컴퓨터로 옮기고 그 반 자료를 지웁니다.

이유 자료 파일은 교사 컴퓨터에서 채점 기록으로 만드는 json입니다(형식: kind "suhaeng-reason"). 이유 자료 없이 일람표만 올리면 원래 서명기처럼 점수 확인과 서명만 합니다.

## 출처
국어 선생님이 만든 수행평가 일람표 전자서명기(https://github.com/koreantch-stack/suhaengsign)를 고쳐 이유 화면, 점수 맞춤 검사, 질문, 확인 기록, 인터넷 없이 열기, 교사 화면 잠금을 더했습니다. 원 저작자가 README에 "코드는 자유롭게 가져다 고쳐 쓰셔도 됩니다"라고 밝혀 두었습니다. 고친 부분도 같은 조건으로 자유롭게 가져다 쓰셔도 됩니다.
